# Яндекс Станция: озвучка и команды

Это **один skill с двумя режимами**, а не два отдельных skill:

- `speak.sh` произносит пользовательский текст голосом Алисы;
- `command.sh` передаёт текст Алисе как команду для музыки, таймеров и умного дома.

Оба режима используют один `SKILL.md`, один `.env` и один Glagol/Quasar-клиент.

## Озвучка текста

Когда пользователь пишет **«скажи в станции: <текст>»**, **«скажи на станции: <текст>»** или **«скажи в Яндекс Станции: <текст>»**:

1. Записать точный пользовательский текст через `write_file` в `/root/.hermes/cache/scratch/station-speech.txt`. Не подставлять пользовательский текст в shell-команду.
2. Выполнить фиксированную команду, которая читает файл и передаёт текст отдельным аргументом без shell-интерполяции:

   ```bash
   python3 -c 'import os, pathlib, subprocess; h=os.environ.get("HERMES_HOME", str(pathlib.Path.home()/".hermes")); p=pathlib.Path(h)/"skills/smart-home/yandex-station-speak/speak.sh"; t=pathlib.Path("/root/.hermes/cache/scratch/station-speech.txt").read_text(); raise SystemExit(subprocess.run([str(p), t]).returncode)'
   ```
3. Удалить временный файл фиксированной командой после выполнения.

- Обычную фразу озвучивать без уточнения: команда пользователя уже является явным поручением.
- Передавать только пользовательский текст после триггера; не добавлять пояснения, код, команды или секреты.
- После выполнения кратко сообщить результат.
- Для текста длиннее 500 символов попросить его сократить.
- `--nopause` применять только по явной просьбе говорить поверх музыки.

## Команды Алисе

Когда пользователь пишет **«команда Алисе: <текст>»**, **«попроси Алису: <текст>»** или явно просит выполнить действие на подключённом умном доме:

1. Записать точный пользовательский текст команды через `write_file` в `/root/.hermes/cache/scratch/alice-command.txt`. Не строить shell-строку с пользовательским текстом.
2. Выполнить фиксированную команду:

   ```bash
   "${HERMES_HOME:-$HOME/.hermes}/skills/smart-home/yandex-station-speak/command.sh" --file /root/.hermes/cache/scratch/alice-command.txt
   ```
3. Удалить временный файл после выполнения.

Команда передаётся через Glagol `sendText`, как если бы пользователь произнёс её рядом с колонкой. Примеры: включить или выключить свет, запустить музыку, поставить таймер, выполнить сценарий умного дома.

Обычные команды света, музыки и таймеров выполнять без уточнения. Перед командами, которые могут повлиять на физическую безопасность или причинить ущерб (замки, ворота, сигнализация, нагреватели, духовка), запросить явное подтверждение. Запуск любого сценария с неизвестным составом действий тоже требует подтверждения.

## Поведение

По умолчанию выполняется полный цикл:

1. определить, играла ли музыка;
2. сохранить текущую громкость;
3. поставить музыку на паузу;
4. установить громкость 80%;
5. произнести фразу голосом Алисы;
6. дождаться конца фразы;
7. вернуть громкость;
8. продолжить музыку, только если она играла до сообщения.

При ошибке отправки скрипт всё равно пытается восстановить громкость и музыку.

## Команды

Полный цикл:

```bash
"${HERMES_HOME:-$HOME/.hermes}/skills/smart-home/yandex-station-speak/speak.sh" 'ТЕКСТ'
```

Поверх музыки без изменения громкости:

```bash
"${HERMES_HOME:-$HOME/.hermes}/skills/smart-home/yandex-station-speak/speak.sh" --nopause 'ТЕКСТ'
```

Команды Алисе из агента всегда передавать только через описанный выше режим `--file`. Прямой позиционный аргумент допустим для ручного вызова человеком, но агент не должен строить из пользовательского текста shell-строку.

Проверка устройств:

```bash
cd "${HERMES_HOME:-$HOME/.hermes}/skills/smart-home/yandex-station-speak"
python3 scripts/tts_dialog.py --list-devices
```

Получение `MUSIC_TOKEN`:

```bash
"${HERMES_HOME:-$HOME/.hermes}/skills/smart-home/yandex-station-speak/.token-venv/bin/python" \
  "${HERMES_HOME:-$HOME/.hermes}/skills/smart-home/yandex-station-speak/get_music_token.py"
```

Токен сохраняется прямо в `.env` с правами `0600`; не просить пользователя присылать его в чат.

## Ограничения

- Хост должен видеть Станцию в локальной сети на TCP 1961.
- Требуются `MUSIC_TOKEN`, `DEVICE_ID`, `DEVICE_PLATFORM` и `STATION_IP` в `.env`.
- Glagol недокументирован и может измениться после обновления прошивки.
- На Linux задавать статический `STATION_IP`; macOS дополнительно поддерживает mDNS через `dns-sd`.
